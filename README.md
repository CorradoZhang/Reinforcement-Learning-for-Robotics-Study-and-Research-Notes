# Reinforcement Learning for Robotics: A Learning Guide

Welcome. This guide is designed as a teaching-oriented path for learning reinforcement learning with robotics in mind.

Instead of reading these posts as isolated notes, treat them as a sequence of lessons. Start from the core ideas, build the mathematical foundation, then move toward deep reinforcement learning, modern research topics, and practical tools for experiments.

## How to Learn

1. Begin with the roadmap post to understand what reinforcement learning is, why it matters for robotics, and which topics should be learned first.
2. Read slowly through the fundamentals. Focus on MDPs, value functions, Bellman equations, dynamic programming, Monte Carlo methods, and TD learning before jumping into deep RL.
3. Move to deep reinforcement learning once the classical ideas feel familiar. Algorithms such as DQN, DDPG, PPO, TD3, and SAC become much easier when the foundation is clear.
4. Use the research topics section to connect the basics with current directions such as offline RL, model-based RL, and world models.
5. Return to the tools section when you are ready to implement experiments or compare RL frameworks.

## Suggested Reading Style

Do not try to memorize every algorithm at once. For each lesson, ask:

- What problem is this method trying to solve?
- What assumptions does it make?
- What changes when the environment becomes continuous, high-dimensional, or robotics-oriented?
- Which paper, course, or tool should I revisit when I need more depth?

New lessons will be added here as the study path expands.
